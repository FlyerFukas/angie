# Angie

A Turkish-speaking personal assistant in Telegram. One message answers questions that would otherwise take four apps: the calendar, email, tasks and contacts.

## Problem
Checking a meeting, an email and a task means opening several apps. The n8n template the assistant started from no longer worked on n8n 2.x.

## Result
- Runs on n8n 2.x for a single, identity-locked Telegram account.
- Fixed 4 bugs in the original template and documented 10 n8n 2.x pitfalls.
- Case study: https://furkanakduman.vercel.app/work/angie
